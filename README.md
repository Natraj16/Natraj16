## Featured Projects

**[Caloriq](https://caloriq-six.vercel.app)** — Nutrition app with an AI coach ("Grit") built on LangChain, using Redis-persisted conversation memory and function calling for real database actions.

**[LogSight](https://github.com/Natraj16/Intelligent-Log-Analyzer)** — Final-year project: a pip-installable log-analysis tool (`pip install logsight`) using a custom anomaly-detection algorithm (QFAD), benchmarked on Loghub datasets, with an accompanying IEEE paper.

**[Invoize](https://invoize.onrender.com)** — AI-powered document extraction engine (Document AI / IDP) built with Gemini 2.5 Flash, FastAPI, PostgreSQL, and Pydantic.

**Microservices Traffic Manager & Rate Limiter** — Java/Spring Boot portfolio project using Redis, Netflix Eureka, and Spring Cloud Gateway across multiple standalone services.
